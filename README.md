# Installation

### <b><u>Pre-requis :</u></b>

Pour pouvoir demarrer le projet sur votre ordinateur, il vous faut les techno suivant : <br/>

- [Git](https://www.git.com) <i>de preference derniere version</i>
- [Node](https://www.node.org) <i>version LTS</i>
- Une bonne connexion internet

### <b><u>Etape a suivre :</u></b>

Si tout est OK, suivez les etapes suivant pour generer votre logiciel selon votre systeme d'exploitation :

1. Cloner le projet : <br/>
   `git clone https://www.github.com/bendev99/gestion_stock.git`
2. Entrer dans le dossier : <br/>
   `cd gestion_stock`
3. Installer les dependances : <br/>
   `npm install`
4. Generer le logiciel en fonction de votre OS : <br/>
   `npm run dist -- --win` (Pour un logiciel `.exe` Windows)<br/>
   `npm run dist -- --linux` (Pour un fichier `.AppImage` Linux)<br/>
   `npm run dist -- --mac` (Pour un fichier `.dmg` Mac OS)<br/>
